# Atividade 2 — Página de Agendamento com Material UI

Projeto React + TypeScript + Vite usando componentes prontos do **Material UI (MUI)** e **MUI X Date Pickers**.

## O que foi implementado

- AppBar para identificação do serviço.
- Stepper com 4 etapas: Serviço, Data e horário, Seus dados e Confirmação.
- Cards selecionáveis para os serviços.
- DatePicker em português com bloqueio de datas passadas.
- ToggleButtonGroup para escolha de horários.
- TextFields para dados do cliente.
- Cards, Paper, Chip, Alert e Snackbar para feedback e resumo.
- Validação básica de cada etapa.
- Confirmação do agendamento com mensagem de sucesso.
- Layout responsivo para desktop e celular.

## Executar

```bash
npm install
npm run dev
```

Para validar a build:

```bash
npm run build
```
